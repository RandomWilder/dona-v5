# 5.0-cut — delete the speculative kernel while the migrations are still editable

**Claimed:** two kernel modules written at 1.4 ahead of a caller still had none at week 5, and the
window to remove their tables closes when Dona Dom's real register arrives (`docs/from-v3.md`).

**Proved.** `createEventBus` and `createIdempotency` were imported by nothing but their own tests —
grep across `src`, `tests`, `evals`, `scripts` returned four files, all four deleted here. Every
other mention (`register/internal/importer.ts:9`, `kernel/migrate.test.ts:25`) was a comment saying
the caller does not exist.

| production lines | 14,642 | 14,466 (**−176**) |
| test lines | 12,804 | 12,584 (**−220**) |
| tables, fresh migrate | 29 | **27** |
| code tests | 483 | 476 (−7, all in the two deleted suites) |
| policy cases | 50 | **50 — untouched** |

`npm test` · `npm run test:policy` · `npm run guards` · `npm run typecheck` · `npm run lint` all
green. Fresh `npm run migrate` into an empty database applies all 21 files and yields 27 tables with
no `outbox` and no `idempotency_keys`.

**Three items in the approved plan were wrong and were not done.** Each was asserted from a grep the
slice repeated and disproved:

- `kernel/embeddings.ts` (346 lines) — claimed zero importers. `evals/corpus.ts:6` imports it and
  `evals/corpus.test.ts:13` uses `createFakeEmbedder`. It is the retrieval half of the golden-set
  gate. **Kept.**
- `CREATE EXTENSION vector` — claimed unused because no migration declares a vector column.
  `evals/corpus.ts:198` builds `CREATE TEMP TABLE eval_chunk (… embedding vector(1536))` at runtime.
  **Kept**, and the extension is genuinely load-bearing rather than speculative.
- `scope/internal/isolation-join.ts:254` `resolvePartiesInUnit` — claimed no caller outside its own
  test. `scripts/measure-scale.ts:196` calls it as the N+1 baseline the batched query is measured
  against. **Kept.**

The fourth item — "~150 lines of dead read-model queries and constants" — was sized by an
unused-export sweep and does not exist. 61 exported names have no reader outside their own file, but
all but two (`ui/assets.ts registerHtmlPage`, `staff/internal/accounts.ts assignRole`, ~34 lines
together) are types or internal helpers their own module calls. `assignRole` gets its first caller
in 5.1b. **Not done.**

**Net: 396 lines and 2 tables, against the plan's claim of ~1,050 and 3.** The plan's 14%-dead
figure was roughly 3%.

**Opened.** The local `dona` database still carries `outbox` and `idempotency_keys`: the ledger is
by filename with no checksum (`kernel/migrate.ts:34`), so an edited migration does not re-run.
Rebuilding it needs `DROP SCHEMA`, which `.claude/hooks/guard-bash.mjs` refuses — the director runs
it by hand, or the container volume is recreated. Staging and prod rebuild on their next deploy from
empty. **Owner: 5.1b**, which rebuilds local anyway to test sign-in from an empty `staff_account`.

**Carried.** `work.ts` was left standing, as planned — its durability claim is still unearned
(`evidence/intake.ts:278` ticks inline) and the decision belongs after extraction runs on real
scans. **Owner: post-7.2.**
