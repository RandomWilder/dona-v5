## What was proved

- **The click is an `href`.** `/documents/:id/read?page=N#f-<extracted_field_id>`. No client
  JavaScript. `:target` and `scroll-margin` highlight the stored union box. Page cannot live only
  in the fragment: a missing page defaults to 1, out of range clamps, a non-integer is `invalid`.
- **Estate does not query `extracted_field`.** `listPromotedFieldsForUnit` is injected the same way
  `listLinkedDocuments` is. Stamped rows only. A unit with no stamp sees no מקור section. Another
  unit id returns zero rows.
- **Still no names.** Dates only. Confidence is a percent when Document AI scored the words, omitted
  when pdfjs stored `null`.
- **Three documents.** One unit page fixture carries three stamped values from three document ids;
  each href names its own document, page and field. Live click-through on staging waits on the
  revision that carries this slice — the process already listening on :3000 is the previous
  revision.
