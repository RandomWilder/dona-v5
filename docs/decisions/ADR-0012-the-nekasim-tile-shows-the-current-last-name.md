# ADR-0012 — The נכסים tile shows the current household's last name

- **Date:** 2026-09-28
- **Status:** accepted
- **Supersedes:** the tile sentence of [ADR-0011](ADR-0011-the-tenancies-book-may-name-the-household.md)
- **Does not touch:** search, חוזים לא שלמים, the unit page heading, or any tenant-facing channel.

## The decision

The נכסים unit tile shows the last name of the household that counts today, under that letting's dates. The name is the last word of the person שכירויות already names: the primary tenant, otherwise the first person on the letting. A one-word name is shown whole. A draft's dates on the same tile carry no name. A vacant tile stays nameless, including when a draft is waiting. Co-tenants stay off the tile.

## Why the tile, and only the last name

ADR-0011 left a name on the tile as a later change, so the grid would not become a roll of households. The office now reads the open building on נכסים as the place to see who is in the flat, and the dates are already on that tile. The last name is enough to tell the flats apart. The full name stays on שכירויות and on the tenancy page.
