רישום אפליקציה

זהות נפרדת לכניסה, לארגון הזה בלבד.

entra.microsoft.com → Applications → App registrations → New registration

  1. בשדה Name: Dona Sign-in - Staging
  2. בשדה Supported account types, לבחור: Accounts in this organizational directory only (Single tenant)
  3. בשדה Redirect URI, לבחור Web ולהדביק:
https://dona-staging-r44j24yuaa-zf.a.run.app/staff/auth/microsoft/callback
  1. ללחוץ Register.
  2. כתובת שנייה, לפיתוח מקומי, מוסיפים דרך Manifest: בתוך "web", ברשימה "redirectUris". התוצאה:
"redirectUris": [
  "https://dona-staging-r44j24yuaa-zf.a.run.app/staff/auth/microsoft/callback",
  "http://127.0.0.1:3000/staff/auth/microsoft/callback"
],
  1. ללחוץ Save. במסך Authentication, תחת Web, מופיעות שתי הכתובות.
  2. בדף Overview, להעתיק את Application (client) ID.
להעתיק את הכתובות בדיוק כפי שהן, תו-בתו.
2

יצירת סוד (Client secret)

סיסמת האפליקציה. המערכת מתריעה 30 יום לפני התפוגה.

App registrations → Dona Sign-in - Staging → Certificates & secrets → New client secret

  1. בשדה Description: dona-signin-staging
  2. בשדה Expires, לבחור Custom, 24 חודשים.
  3. ללחוץ Add.
  4. להעתיק מיד את עמודת Value. היא מוצגת פעם אחת.
  5. לרשום את תאריך התפוגה (עמודת Expires), בצורה YYYY-MM-DD.
3

הרשאות: openid ו-User.Read

שתי הרשאות מואצלות (Delegated): זיהוי, וקריאת הפרופיל של העובד שנכנס.

App registrations → Dona Sign-in - Staging → API permissions

  1. User.Read כבר ברשימה.
  2. להוסיף את openid: Add a permission → Microsoft Graph → Delegated permissions → openid → Add permissions
  3. ללחוץ Grant admin consent ולאשר.
התוצאה: openid ו-User.Read, מסוג Delegated, עם סימון ירוק Granted.
